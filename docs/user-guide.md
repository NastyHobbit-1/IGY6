# User Guide

The local web UI provides a read-only operational inventory.

Open:

```text
http://127.0.0.1:3000
```

The page shows API readiness checks plus source, collection-run, and raw
artifact metadata from FastAPI. It does not create sources, run collection,
upload files, normalize content, approve actions, generate chat answers,
predict, recommend, or run experiments.

Future phases will add evidence inspection, chat/review, pattern review,
prediction/outcome tracking, reports, and self-improvement controls.
