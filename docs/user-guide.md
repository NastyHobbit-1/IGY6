# User Guide

Phase 0 provides only a local status page.

Open:

```text
http://127.0.0.1:3000
```

The page shows API readiness checks. It is not a chat interface and does not
collect, index, analyze, predict, recommend, or run experiments.

Future phases will add source registration, dry-runs, evidence inspection,
chat/review, pattern review, prediction/outcome tracking, reports, and
self-improvement controls.
