# User Guide

The local web UI provides a read-only operational inventory.

Open:

```text
http://127.0.0.1:3000
```

The page shows API readiness checks, source records, collection-run metadata,
raw artifact metadata, normalized documents, chunks, evidence items, and claims
from FastAPI. It does not create sources, run collection, upload files,
normalize content, generate chunks, create evidence, approve actions, generate
chat answers, predict, recommend, or run experiments.

Future phases will add memory inspection, chat/review, pattern review,
prediction/outcome tracking, reports, and self-improvement controls.
