# User Workflow

1. Start IGY6 stack using Docker Compose.
2. Open the web UI at http://127.0.0.1:13000.
3. Add authorized information in the Data tab.
4. Review ingested evidence and provenance.
5. Ask evidence-grounded questions in Chat.
6. Monitor work items if supported in current runtime.
7. Stop/restart the stack using Docker Compose commands.

Do not commit .env files, .env.test, or contents of the IGY6_DATA_ROOT directory.
